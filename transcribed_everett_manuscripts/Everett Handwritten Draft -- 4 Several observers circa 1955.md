Care 3: We suppose that two systems \(S_1\) and \(S_2\) are correlated but no longer interacting, and that \(O_1\) measures property \(A\) in \(S_1\), and \(O_2\) property \(B\) in \(S_2\). We wish to see whether \(O_1\)'s intervention with \(S_2\) can in any way affect \(O_2\)'s results in \(S_1\), so that perhaps signals might be sent by these means.

We shall assume that the initial state for the system pair is

\[
\psi_{S_1 S_2} = \sum_{i} \phi_i^S \psi_i^S
\]

We now allow \(O_2\) to have \(A\) in \(S_1\), so that after this operation the total state becomes:

\[
\psi_{S_1 S_2 O_2} = \sum_i \phi_i^S \psi_i^S \sum_j \psi_j^O \psi_j^O

\(O_2\) can of course continue to repeat the alternation, obtaining the same result each time.

We now suppose that \(O_2\) alternates \(B\) in \(S_2\), which results in

\[
\psi'' = \sum_{i,j} \alpha_{ij} \phi_i^S \psi_j^O \psi_j^O \sum_{i,j} \psi_i^O \psi_i^O
