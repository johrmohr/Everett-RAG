# Everett Handwritten Draft -- 5 The wave interpretation circa 1955.pdf

The wave-interpretation: this is the position proposed in the present thesis, in which the wave function itself is held to be the fundamental entity, obeying at all times a deterministic wave equation. The view advocated most clearly with that of Schrödinger. However, this picture only makes sense when observation presents themselves as treated within the theory, since it is only in this manner that one can see that optics, etc. will appear to have definite positions etc. (independent particle nature can be understood, even though the waves are not in the same way as in the wave theory). With this deduction of the appearance of phenomena to be observed, Heisenberg's criticism of Schrödinger's opinion that continuous wave mechanics could not explain the discontinuities which are everywhere observed - is effectively met. The wave picture is definitely tenable and we believe, to the fullest complete, self-consistent theory.

The quantum-wave will in our theory as a relation phenomenon - this state of an object system relative to chosen observer states show this effect, while the absolute state change gets cancelled.
